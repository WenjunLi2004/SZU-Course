## 2024.1.6 期末考试

难度：简单。

### 机考

- 共五题，前四题比较容易，涉及排序、树遍历和查找。
- 第五题：给定邻接矩阵，求长度为 `m` 的环有几个（环的边数和顶点数都是 `m`）。

### 选择与填空

- 栈和队列的共同点。
- 快速排序的平均时间复杂度。
- 树、图的常见知识点，例如叶子结点数量。
- 根据排序的中间结果判断排序方法。

### 大题

1. **KMP 算法**
   - 求 `next` 数组（直接写结果）。
   - 写出 KMP 匹配的具体过程。
2. **无向网的最小生成树**
   - 画无向网。
   - 写邻接表。
   - 使用 Prim 或 Kruskal 算法求最小生成树。
3. **查找结构**：给定序列，选择查找次数最优的结构；本题选择 AVL，并画平衡二叉树。
4. **图与树的综合题**：关键路径、WPL、DFS，并画有向网。
5. **排序**：堆排序、希尔排序、二路归并排序。
6. **查找**：构建二分查找判定树，并分析 ASL。
