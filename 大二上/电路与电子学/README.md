## 题型

1. **填空题**——

   大多考积分电路，放大电路，差动放大电路，和第四章习题类似，都是基本概念

2. **七个大题**

## 大题

1. **受控源**（没掌握，写错了 QAQ）

   受控源电路分析、戴维南等效。

2. **节点电位法**：两个电位之间有电压源，需要假设一个 `ix`。

3. **一阶电路分析**：求普通电流 `i(t)`。注意看题，零时刻开关关闭被我看成打开了，浪费了很多时间。

4. **交流电路计算**：包含两个并联和两个串联。想一步到位用计算器没有得到结果，分开计算反而更省时间。

5. **静态工作点分析**：判断静态工作点偏大时应调节 `Rb` 还是 `Re`，并分析调节后的影响。

6. **放大电路**：静态和动态分析，并计算相关参数。

7. **积分电路**：画波形图并列出表达式。
