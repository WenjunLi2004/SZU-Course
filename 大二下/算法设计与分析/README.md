## 大题

1. **主定理和递归树**
   - 判断不平衡的递归树能否使用主定理求解：`T(n) = T(n/3) + T(2n/3) + O(n)`。
   - 使用主定理求解递推式，并画出递归树。
2. **分治算法**：找出数组中出现次数大于 `n/2` 的元素。
   - 说明算法思想和合并过程。
   - 使用序列 `2 2 1 1 1 2 2` 讲述递归过程。
   - 写出伪代码。
3. **回溯法求解数独**
   - 根据已经填写部分数字的图，画出搜索树下面两层。
   - 写出剪枝策略。
   - 分析算法效率。
4. **贪心算法解决会议室安排问题**
   - 给出贪心算法，确定至少需要多少个会议室。
   - 说明所需的数据结构及其在贪心过程中的用法。
5. **动态规划**：九宫格从左上走到右下，每个格子有一个值，值为 `-1` 表示不能经过。
   - 写出 DP 方程。
   - 根据给定的 `3 × 3` 矩阵写出填表过程和 DP 表。
   - 分析算法效率。
6. **最大流**：节点存在容量限制，将节点拆分为 `in` 和 `out`，再转化为普通最大流问题。
