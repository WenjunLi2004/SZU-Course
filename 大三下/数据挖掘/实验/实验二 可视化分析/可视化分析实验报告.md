### 3. 任务一：绘制每类商家 10 月份的日平均客流量折线图

#### 3.1 数据筛选与分组统计

该任务对应实验指导书中“绘制每类商家 10 月份的日平均客流量折线图”。由于读取数据时已经将 `time_stamp` 设置为时间索引，因此可以直接通过 `df.index.month == 10` 筛选 10 月份数据。

筛选完成后，需要按照“日期”和“商家类别”两个维度分组，并对 `pay_num` 求平均值。代码中使用 `normalize()` 将时间索引统一到当天零点，确保统计粒度为“日”；再通过 `unstack()` 将商家类别展开为列，形成适合多折线绘图的二维表。

```python
october_data = df[df.index.month == 10].copy()

october_daily_avg = (
    october_data
    .groupby([october_data.index.normalize(), 'cate_2_name'])['pay_num']
    .mean()
    .unstack()
    .sort_index()
)
```

#### 3.2 折线图绘制

绘图时使用 pandas 封装的 `plot(kind='line')`。为保证不同类别曲线能够区分，设置线宽、标记点和透明度；同时将图例放到图外，避免遮挡折线。

```python
import matplotlib.dates as mdates

ax = october_daily_avg.plot(
    kind='line',
    figsize=(13, 7),
    linewidth=2.2,
    marker='o',
    markersize=4,
    markevery=3,
    alpha=0.9
)

ax.set_title('每类商家 10 月份的日平均客流量折线图')
ax.set_xlabel('日期')
ax.set_ylabel('日平均客流量')
ax.grid(axis='y', linestyle='--', alpha=0.35)
ax.xaxis.set_major_locator(mdates.DayLocator(interval=3))
ax.xaxis.set_major_formatter(mdates.DateFormatter('%m-%d'))
ax.legend(title='商家类别', frameon=False, loc='upper left', bbox_to_anchor=(1.01, 1.0))

plt.xticks(rotation=35, ha='right')
plt.tight_layout()
plt.show()
```

### 4. 任务二：绘制指定商家每月总客流量柱状图

#### 4.1 筛选指定商家并按月汇总

该任务对应实验指导书中“选择一个商家，统计每月的总客流量，绘制柱状图”。Notebook 中选择的商家编号为 `shop_id == 14`。筛选出该商家的记录后，直接对 `pay_num` 使用 `resample('ME').sum()` 按月汇总，其中 `ME` 表示月末频率，`sum()` 表示计算该月总客流量。

```python
shop_id_target = 14
shop_data = df[df['shop_id'] == shop_id_target].copy()

monthly_total = shop_data['pay_num'].resample('ME').sum()
monthly_total.index = monthly_total.index.strftime('%Y-%m')
```

#### 4.2 柱状图绘制

绘制柱状图时使用 `plot(kind='bar')`。为了便于读取每个月的客流量，在每个柱体顶部添加数值标注。

```python
ax = monthly_total.plot(
    kind='bar',
    figsize=(12, 6),
    color='#7DB7E8',
    edgecolor='#2F4F4F',
    linewidth=1.0,
    width=0.7
)

ax.set_title(f'商家 {shop_id_target} 每月总客流量柱状图')
ax.set_xlabel('月份')
ax.set_ylabel('月总客流量')
ax.grid(axis='y', linestyle='--', alpha=0.35)

for bar in ax.patches:
    h = bar.get_height()
    ax.annotate(f'{h:.0f}', (bar.get_x() + bar.get_width() / 2, h),
                ha='center', va='bottom', fontsize=9)

plt.xticks(rotation=35, ha='right')
plt.tight_layout()
plt.show()
```

### 5. 任务三：绘制 10 月各类别商店总客流量占比饼图

#### 5.1 统计各类别总客流量

该任务对应实验指导书中“统计某个月各个类别商店总客流量占该月总客流量的比例，绘制饼图”。Notebook 中选择的月份为 10 月。首先筛选 10 月份数据，再按照 `cate_2_name` 分组，对 `pay_num` 求和，得到各类别商店在 10 月份的总客流量Notebook 中选择的月份为 10 月。首先筛选 10 月份数据，再按照 `cate_2_name` 分组，对 `pay_num` 求和，得到各类别商店在 10 月份的总客流量。

```python
october_category_total = (
    df[df.index.month == 10]
    .groupby('cate_2_name')['pay_num']
    .sum()
    .sort_values(ascending=False)
)
```

#### 5.2 饼图绘制

饼图用于表现各类别客流量在整体中的占比。为避免图中文字过密，代码中不直接在扇区旁显示类别名称，而是将类别名称统一放入图例；同时通过 `fmt_pct()` 只显示占比不小于 3% 的百分比文本。

```python
def fmt_pct(pct):
    return f'{pct:.1f}%' if pct >= 3 else ''

fig, ax = plt.subplots(figsize=(9.5, 8))
wedges, texts, autotexts = ax.pie(
    october_category_total.values,
    labels=None,
    autopct=fmt_pct,
    startangle=110,
    counterclock=False,
    pctdistance=0.72,
    wedgeprops={'edgecolor': 'white', 'linewidth': 1.2}
)

ax.set_title('10 月各类别商店总客流量占比饼图')
ax.legend(wedges, october_category_total.index, title='商家类别',
          loc='center left', bbox_to_anchor=(1.02, 0.5), frameon=False)
ax.set_aspect('equal')

plt.tight_layout()
plt.show()
```

#### 5.3 结果说明

该饼图用于展示 10 月份不同类别商店总客流量占整体客流量的比例。扇区面积越大，表示该类别在当月整体客流量中的占比越高；图例用于对应不同扇区所代表的商家类别。

## 【三、实验体会】

一开始我以为本次实验的重点只是把数据读进来，然后调用 `plot()` 画出折线图、柱状图和饼图即可。实际操作时才发现，图能不能正确表达问题，关键不在绘图语句本身，而在绘图之前的数据索引、筛选条件和分组粒度是否正确。如果时间字段没有在读取阶段解析为日期类型，后面就无法自然地使用月份筛选和按月重采样，代码也会变得更零散。

我在处理 10 月份日平均客流量时，最容易混淆的是“总客流量”和“平均客流量”的区别。这个任务要求的是每类商家的日平均客流量，因此分组时不能只按类别求和，也不能只按日期求平均，而是要同时按日期和商家类别分组，再对 `pay_num` 求平均。理解这一点后，我才意识到 `groupby([日期, 类别])` 和 `unstack()` 是连续配合使用的：前者负责得到正确的统计粒度，后者负责把长表整理成适合多条折线展示的宽表。

在绘制指定商家月总客流量柱状图时，我最初更倾向于手动提取年份和月份再进行分组，但这样做容易增加中间字段，也容易让代码显得复杂。后来改用 `resample('ME').sum()` 后，整个逻辑变得更直接：因为索引已经是时间索引，所以按月汇总本来就是时间序列数据应有的处理方式。这让我更加理解了实验指导书中强调 `parse_dates` 和时间索引的原因。

饼图部分的主要问题不是统计，而是图表可读性。类别较多时，如果把类别名称和百分比都挤在扇区周围，图面会很乱。最终我采用“扇区只显示主要百分比，类别名称放入图例”的方式，使结果更容易阅读。通过这次实验，我对 pandas 绘图接口和 matplotlib 图表对象之间的关系有了更清楚的认识，也理解了可视化分析并不是简单地生成图片，而是要让数据统计口径、图表类型和阅读效果保持一致。
