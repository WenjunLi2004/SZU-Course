## 期末考试回忆 (2026 春)

### 选择题（15 × 2 分）

大部分题目较简单。以下为易错点：

- 虚拟存储器的特征。
- 引入时间片轮转调度（RR）的目的：**提高响应速度，而不是提高吞吐率**。

### 简答题

1. 进程和程序的区别。
2. 什么是死锁？引发死锁的四个必要条件是什么？
3. 简述分页存储管理的优点。
4. 什么是设备独立性？举例说明设备独立性的两个好处。
5. 简述 FAT 表如何管理文件所占用的盘块。

### 计算题

1. **磁盘调度算法**：SCAN、FCFS。
2. **银行家算法**。
3. **页面置换算法**：LRU、FIFO。
4. **进程调度**：FCFS、SPF，计算平均周转时间。
5. **文件系统**：磁盘块大小为 1 KB，盘块地址为 4 B；FCB 的索引结构包含 10 个直接地址、1 个一级间接地址和 1 个二级间接地址。分别计算仅使用直接地址、直接地址加一级间接地址、直接地址加一级和二级间接地址时的文件最大长度。
   - ⚠️ 注意：文件长度单位为 **KB**，计算结果务必标明单位。

### 编程题

代码补全 + PV 操作。题干为高优先级任务和普通任务共享一个 GPU 资源：

- 高优先级任务优先执行；
- 当有普通任务等待，且高优先级任务已连续完成三次时，高优先级任务让权给一个普通任务执行。
