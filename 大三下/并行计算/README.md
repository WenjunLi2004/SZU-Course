## 期末考试回忆 (2026 春)

1. 画分布式内存示意图，并分析特点
2. 监听（Snooping）缓存一致性的原理
3. 程序改错：MPI 死锁，两个进程同时 Send —— 解决方案 `MPI_Sendrecv`
   > ⚠️ 踩坑：考场上灵机一动，觉得 `MPI_Sendrecv` 反正是两边互发，两个 tag 和 dest 参数"没必要"区分，实则不一定——发送目标和接收来源、发送 tag 和接收 tag 完全可以不同，血亏！
4. 计算 Cannon 算法执行时间：n 阶方阵 C = A ✖️ B，A、B、C 存储在 p 个处理器中，单数据的传输开销 ts，通信开销为 td
5. 程序改错：`omp parallel for` 计算前缀和，执行顺序上的数据依赖 `b[i] = b[i-1] + a[i]`
6. 程序改错：Pthreads 伪共享，8 ✖️ 8000000 的例子
7. 解释多线程并发修改同一共享变量（结果出错）的原因
8. 给定 n、p，分析 PSRS 的时间复杂度
9. 简述 CUDA 线程层次结构
10. 双调序列的定义；双调排序的基本原理；解释该算法适配 CUDA GPU 的原因
