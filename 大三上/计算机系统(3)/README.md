- **最后一题**：问如何提升虚拟物理地址转换的速度
  - A: 加大 TLB
  - B: 让页表常驻内存
  - C: (忘了)

### 简答题
0. 优化后的乘法器每个部件的名字（丢分点在64bit的乘积和被乘数，哪个在左哪个在右）
1. `beq` 和 `j` 指令计算出地址在哪个阶段？为什么 `beq` 指令更容易受到阻塞？
2. BTB (Branch Target Buffer) 有什么作用？如何有效减少冒险？
3. TLB 是什么？在虚实地址转换中有什么作用？

### 大题
1. **浮点数运算**（和王曦学长的第一道大题一样）：
   - 浮点数两个 ALU 的作用
   - 补全浮点数图（从原始的 SEF 连接到下一层的线）
   - 规范化的两个部件是否协同？是的话，如何协同（即分析左右移和自增/减的关系）
2. **J 指令**：画出 J 指令的地址更新电路图
3. **控制信号**：控制信号和指令的关系
   - 考法：如果某些控制信号被强制设置为 0，哪些指令不能正常工作？
   - 例如：`RegDst=0`，`add` 就不能正常工作
4. **数据冒险**：
   - 画时空图
   - 判断数据冒险类型并给出解决方案
   - 画出前推电路图（这次考的是 MEM 冒险前推）
5. **存储层次结构** (TLB-页表-D-Cache-内存-硬盘)：
   - 判断访问是否会发生，如果发生，计算时间
   - 例如：TLB 未命中，页面未命中，Cache 命中
   - 这三个的排列组合共有 8 种情况，需逐个判断
